Riuso prima di tutto

Le ontologie riusate e la piccola estensione custom del progetto.

Approccio: riuso prima di tutto

Coerentemente con le buone pratiche del web semantico, il progetto non ridichiara classi o proprietà già disponibili nelle ontologie ufficiali della Pubblica Amministrazione italiana. Vengono riusate per IRI così come definite nei rispettivi namespace:

  • cov: — Core Organization Vocabulary (organizzazioni/gestori)
  • clv: — Core Location Vocabulary (indirizzi, geometrie, distretti)
  • poi: — Points of Interest (le Case come punti di interesse)
  • ti: — Time Interval (giorni della settimana)
  • ac: — Access Condition (orari di apertura)
  • arco: — ArCo (beni architettonici storici)

L'intera rete di vocabolari controllati OntoPiA è mantenuta e documentata dal team Developers Italia: github.com/italia/daf-ontologie-vocabolari-controllati.

Estensione custom — namespace bo:

Solo dove le ontologie riusate non coprivano un concetto specifico del dominio, è stata introdotta una piccola estensione con prefisso bo: (https://example.org/casediquartierebologna#):

Classe: bo:CasaDiQuartiere

Sottoclasse di poi:PointOfInterest — rappresenta lo spazio comunitario stesso.

bo:CasaDiQuartiere
    a owl:Class ;
    rdfs:subClassOf poi:PointOfInterest ;
    rdfs:label "Casa di Quartiere"@it ;
    rdfs:comment "Spazio comunitario gestito da associazioni del terzo
        settore, parte della rete istituzionale del Comune di Bologna."@it .

Proprietà: bo:isManagedBy

Collega una Casa all'organizzazione (cov:PrivateOrganization) che la gestisce — colonna gestore del CSV.

bo:isManagedBy
    a owl:ObjectProperty ;
    rdfs:domain bo:CasaDiQuartiere ;
    rdfs:range cov:PrivateOrganization ;
    rdfs:label "è gestita da"@it .

Proprietà: bo:isLocatedInHeritageBuilding

Collega una Casa al bene architettonico ArCo che la ospita, quando l'edificio è ufficialmente catalogato come patrimonio storico.

bo:isLocatedInHeritageBuilding
    a owl:ObjectProperty ;
    rdfs:domain bo:CasaDiQuartiere ;
    rdfs:range arco:ArchitecturalOrLandscapeHeritage ;
    rdfs:label "è ubicata nell'edificio storico"@it .
Consistenza verificata con il reasoner HermiT in Protégé: nessuna inconsistenza logica rilevata sul grafo completo (schema + 32 istanze). Dettagli in Sfide.

Esempio di istanza

Un esempio (semplificato) di come i pattern si combinano per una singola Casa di Quartiere:

bo:CasaEsempio a bo:CasaDiQuartiere ;
    poi:POIID "CQ99" ;
    poi:POIofficialName "Casa Esempio"@it ;
    clv:hasAddress bo:AddressCasaEsempio ;
    clv:hasGeometry bo:GeometriaCasaEsempio ;
    bo:isManagedBy bo:GestoreCasaEsempio ;
    sm:hasWebSite <http://www.esempio-casa.it> ;
    ac:hasAccessCondition bo:OrarioCasaEsempio_Lun_Mattina .

bo:AddressCasaEsempio a clv:Address ;
    clv:hasStreetToponym bo:ViaEsempio ;
    clv:hasNumber bo:Civico22_3 ;
    clv:hasDistrict bo:QuartierePortoSaragozza ;
    clv:hasCity bo:ComuneBologna .

bo:OrarioCasaEsempio_Lun_Mattina a ac:OpeningHoursSpecification ;
    ac:opens "09:00:00"^^xsd:time ;
    ac:closes "13:00:00"^^xsd:time ;
    ac:hasDayOfWeek ti:Monday .

Lo schema completo (con tutte le note di modellazione) è disponibile per il download: schema_case_di_quartiere.ttl

Caricare in data/schema_case_di_quartiere.ttl il file Turtle completo dello schema.
