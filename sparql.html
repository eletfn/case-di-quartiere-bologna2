Query SPARQL

Le interrogazioni, per knowledge graph

Ogni query è riportata nella versione realmente eseguita — incluse quelle che hanno prodotto errori o risultati poi rivisti, perché il percorso di tentativi ed errori è parte della metodologia.

Ricerca per classe candidata (community centre)

Endpoint: query.wikidata.org

SELECT DISTINCT ?item ?itemLabel ?class ?classLabel ?coord ?website WHERE {
  ?item wdt:P31 wd:Q77115 .
  ?item wdt:P131 wd:Q1891 .          # situato a Bologna
  OPTIONAL { ?item wdt:P625 ?coord. }
  OPTIONAL { ?item wdt:P856 ?website. }
  SERVICE wikibase:label { bd:serviceParam wikibase:language "it,en". }
}
ORDER BY ?itemLabel

Risultato: 3 elementi (Centro Costa, Centro sociale della Pace, Isola nel Kantiere). Verifica manuale: solo i primi due corrispondono a Case di Quartiere reali del dataset comunale.

Estrazione empirica delle proprietà usate

SELECT DISTINCT ?item ?itemLabel ?propLabel ?value ?valueLabel WHERE {
  VALUES ?item { wd:Q106087121 wd:Q124358767 wd:Q106061123 wd:Q106084039 wd:Q25403967 }
  ?item ?p ?value .
  ?prop wikibase:directClaim ?p .
  SERVICE wikibase:label { bd:serviceParam wikibase:language "it,en". }
}
ORDER BY ?itemLabel ?propLabel

Risultato: vocabolario osservato — P31, P625, P6375, P131, P276, P1435, P973, P856, P18, tra le altre.

Proprietà della classe Organization (COV-AP_IT)

Endpoint: schema.gov.it/sparql — esplorazione TBox (schema), non ABox.

PREFIX covapit: <https://w3id.org/italia/onto/COV/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT DISTINCT ?property ?propertyLabel ?range WHERE {
  ?property rdfs:domain covapit:Organization .
  OPTIONAL { ?property rdfs:label ?propertyLabel . FILTER(lang(?propertyLabel) = "it") }
  OPTIONAL { ?property rdfs:range ?range . }
}

Risultato: proprietà rilevanti individuate — legalName, altName, orgAcronym, taxCode, hasLegalStatus, hasActivityType, hasSubOrganization/subOrganizationOf.

Beni architettonici a Bologna (esempio di struttura query)

Endpoint: dati.beniculturali.it/sparql

PREFIX arco-arco: <https://w3id.org/arco/ontology/arco/>
PREFIX arco-location: <https://w3id.org/arco/ontology/location/>
PREFIX arco-dd: <https://w3id.org/arco/ontology/denotative-description/>
PREFIX CLV: <https://w3id.org/italia/onto/CLV/>

SELECT (count(distinct ?cultpro) as ?count) WHERE {
  ?cultpro a arco-arco:ArchitecturalOrLandscapeHeritage .
  ?cultpro arco-location:hasCulturalPropertyAddress ?address .
  ?address CLV:hasRegion ?region .
  ?region rdfs:label ?regNome .
  FILTER regex(?regNome, "Emilia-Romagna", "i")
}
Sostituire con le query effettivamente eseguite su ArCo per le 3 Case di Quartiere ospitate in edifici storici (ville), con relativi risultati.
